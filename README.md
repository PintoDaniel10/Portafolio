# Mi Portafolio Personal y Profesional

Portfolio de Daniel Pinto - Full Stack Developer .NET & NodeJS

## Tecnologías

- **Backend:** C#, .NET, ASP.NET Core, Node.js, NestJS
- **Frontend:** Angular, TypeScript, HTML5, JavaScript
- **Bases de Datos:** SQL Server, MySQL, Oracle, MariaDB
- **Herramientas:** Git, Docker, Linux
- **IA & Asistentes:** ChatGPT, Copilot, Cursor AI, Claude, GitHub Copilot
- **Metodologías:** Spec-Driven Development, Agile/Scrum

## Diseño

- Tailwind CSS v4 (CDN)
- Dark Mode (sistema + manual)
- Responsive Design (mobile-first)
- Glassmorphism
- Animaciones modernas (CSS + Intersection Observer)

## Secciones

- Inicio (Hero)
- Acerca de mí (Perfil, Stack, Habilidades, IA)
- Portafolio (Proyectos)
- Estudios (Certificaciones, Cursos)
- Experiencia (Timeline laboral)
- Contacto

## Uso

Abrir `index.html` directamente en el navegador o servir con:
```bash
npx serve
```

## Estructura

```
/
├── index.html          # Página principal
├── js/
│   └── main.js        # JavaScript (scroll spy, dark mode, mobile menu)
├── css/
│   └── style.css      # Estilos legacy (deprecated)

├── pdf/               # Curriculum PDF
```
